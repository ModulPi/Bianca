> 版本：v1.0 | 日期：2026-07-28

## 1. 枚举值定义

### 1.1 策略类型 (strategy.type)

| 值 | 含义 | params JSONB 结构 |
|----|------|-------------------|
| `grid` | 网格交易 | `{symbol, upper_price, lower_price, grid_count, invest_per_grid}` |
| `dca` | 定投 | `{symbol, invest_amount, interval_hours}` |
| `trend` | 趋势跟踪 | `{symbol, fast_ma, slow_ma, position_ratio}` |

### 1.2 交易市场 (strategy.market / positions.market)

| 值 | 含义 | 对应币安产品 |
|----|------|-------------|
| `spot` | 现货交易 | Binance Spot |
| `futures_u` | U 本位永续合约 | Binance USDⓈ-M Futures |
| `futures_coin` | 币本位永续合约 | Binance COIN-M Futures |

### 1.3 执行模式 (strategy.execution_mode / trade_logs.execution_mode)

| 值 | 含义 |
|----|------|
| `auto` | 全自动：策略信号 → 风控 → 自动下单 |
| `semi_auto` | 半自动：策略信号 → 推送通知 → 用户确认 → 风控 → 下单 |

### 1.4 策略状态 (strategy.status)

| 值 | 含义 | 允许操作 |
|----|------|----------|
| `created` | 已创建，未启动 | start, update, delete |
| `running` | 运行中 | pause, stop |
| `paused` | 已暂停（保留持仓） | resume(start), stop |
| `stopped` | 已停止（已平仓） | start, delete |

### 1.5 订单方向 (trade_logs.side)

| 值 | 含义 |
|----|------|
| `BUY` | 买入/做多 |
| `SELL` | 卖出/做空 |

### 1.6 订单类型 (trade_logs.order_type)

| 值 | 含义 | price 字段 |
|----|------|-----------|
| `MARKET` | 市价单 | NULL（按市价成交） |
| `LIMIT` | 限价单 | 必填（指定价格） |

### 1.7 交易状态 (trade_logs.status)

| 值 | 含义 | 下一步 |
|----|------|--------|
| `submitted` | 已提交到交易所 | → `partial` / `filled` / `failed` |
| `partial` | 部分成交 | → `filled` / `canceled` |
| `filled` | 完全成交 | 终态 |
| `canceled` | 已取消 | 终态 |
| `failed` | 下单失败 | 终态（可重试） |

### 1.8 风控决策 (trade_logs.risk_decision)

| 值 | 含义 |
|----|------|
| `approved` | 风控通过 |
| `rejected` | 风控拒绝 |

### 1.9 风控事件类型 (risk_events.event_type)

| 值 | 含义 | 触发条件 |
|----|------|----------|
| `stop_loss` | 止损触发 | 价格触及止损线 |
| `daily_loss` | 日亏损熔断 | 当日累计亏损 ≥ 限额 |
| `drawdown` | 回撤熔断 | 总资金回撤 ≥ 最大回撤线 |
| `position_limit` | 仓位超限 | 单币种/总持仓超上限 |
| `leverage` | 杠杆超限 | 合约杠杆 > 最大杠杆 |
| `circuit_breaker` | 熔断器状态变更 | OPEN → HALF_OPEN → CLOSED |

### 1.10 K 线时间框架 (klines.interval)

| 值 | 含义 | 用途 |
|----|------|------|
| `1m` | 1 分钟 | 高频策略、实时监控 |
| `5m` | 5 分钟 | 短期趋势 |
| `15m` | 15 分钟 | 中短期分析 |
| `1h` | 1 小时 | 中期趋势（LLM 分析用） |
| `4h` | 4 小时 | 中长期趋势（LLM 分析用） |
| `1d` | 日线 | 长期趋势、定投参考 |

## 2. 数值精度规范

| 字段类型 | 精度 | 示例 | 说明 |
|----------|------|------|------|
| `NUMERIC(20,8)` | 20 位总长，8 位小数 | `0.00001234 BTC` | 数量、价格 |
| `DOUBLE PRECISION` | IEEE 754 双精度 | `65432.10` | K 线 OHLCV（精度不敏感） |
| `NUMERIC(3,2)` | 0.00 ~ 1.00 | `0.72` | LLM 置信度 |
| `INTEGER` | 32 位整数 | `125` | 杠杆、成交笔数 |

---

## 3. 时区规范

- 所有 `TIMESTAMPTZ` 列存储 UTC 时间
- 前端展示时转换为用户本地时区（如 `Asia/Shanghai`）
- K 线时间：以币安服务器时间为准（UTC）
- 审计日志：以系统时间为准（UTC）
