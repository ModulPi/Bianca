# Bianca 数据字典

> 版本：v0.3 | 日期：2026-07-31

## PoC 表

### trade_logs — 交易/信号记录

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | TEXT | ✅ | UUID 主键 |
| symbol | TEXT | ✅ | 交易对，如 BTCUSDT |
| side | TEXT | ✅ | BUY / SELL / HOLD |
| quantity | REAL | | 数量 |
| price | REAL | | 成交价格 |
| order_type | TEXT | | MARKET / LIMIT |
| llm_confidence | REAL | | LLM 置信度 0.0–1.0 |
| decision_reason | TEXT | ✅ | LLM 决策理由 |
| risk_decision | TEXT | | approved / rejected / skipped |
| risk_reason | TEXT | | 风控拒绝原因 |
| external_order_id | TEXT | | 币安订单 ID |
| status | TEXT | ✅ | signal_only / submitted / filled / failed |
| created_at | TEXT | ✅ | ISO8601 时间 |

### risk_events — 风控事件

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | TEXT | ✅ | UUID 主键 |
| event_type | TEXT | ✅ | max_trade_amount / daily_loss |
| detail | TEXT | ✅ | JSON 详情 |
| related_trade_id | TEXT | | FK → trade_logs.id |
| created_at | TEXT | ✅ | ISO8601 时间 |

### decision_logs — LLM 决策日志

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | TEXT | ✅ | UUID 主键 |
| model_used | TEXT | ✅ | 如 qwen2.5:7b |
| prompt_summary | TEXT | | 输入摘要 |
| raw_output | TEXT | ✅ | LLM 原始输出 |
| parsed_signal | TEXT | ✅ | JSON 结构化信号 |
| created_at | TEXT | ✅ | ISO8601 时间 |

### agent_config — 运行配置

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| key | TEXT | ✅ | 配置键 |
| value | TEXT | ✅ | 配置值 |

## MVP 新增表（概要）

| 表 | 说明 |
|----|------|
| strategies | 策略模板配置 |
| positions | 持仓快照 |
| pending_signals | 半自动待确认信号 |
| paper_validations | 模拟验证记录 |
| analysis_reports | LLM 分析报告 |
| klines | K 线时序（TimescaleDB） |
| api_keys | 加密 API Key 存储 |

详见《数据库设计文档-Bianca.md》和 `sql/002_mvp_postgres.sql`。
