# Bianca — 容量规划报告

> 版本：v0.4 | 日期：2026-07-31

---

## 1. PoC 规模

| 指标 | 值 |
|------|-----|
| 用户数 | 1（开发者本地） |
| 交易对 | 1（BTCUSDT） |
| Agent 循环频率 | 每 5 分钟 |
| 日 LLM 调用 | ~288 次 |
| 日交易次数 | 0–10（LLM 决定） |
| 日数据增量 | < 1 MB（SQLite） |

**结论：** PoC 无性能瓶颈，单机足够。

---

## 2. PoC 资源需求

| 资源 | 最低 | 推荐 |
|------|------|------|
| CPU | 4 核 | 8 核 |
| RAM | 8 GB | 16 GB（切换 Ollama 7B 时） |
| 磁盘 | 10 GB | 20 GB |
| GPU | 无（DeepSeek 云端） | 可选（Ollama 本地加速） |
| 网络 | 稳定访问 demo-api.binance.com | 同 |

---

## 3. MVP 规模预估（PoC 后）

| 指标 | 保守 (1年) | 乐观 (1年) |
|------|-----------|-----------|
| DAU | 10 | 100 |
| 并发策略 | 5 | 50 |
| 监控交易对 | 10 | 100 |
| 日交易 | 50 | 5000 |

### MVP 瓶颈

| 瓶颈 | 触发条件 | 方案 |
|------|----------|------|
| LLM 推理 | 多用户同时分析 | 队列 + 限流 |
| 币安 API 限流 | >50 单/10s | 订单队列 |
| K 线存储 | >90 天历史 | TimescaleDB 压缩 + 保留策略 |
| WebSocket | >200 交易对 | 连接复用 |

---

## 4. 数据增量（MVP）

| 表 | 100 DAU 日增量 | 年增量 |
|----|---------------|--------|
| trade_logs | ~100 KB | ~36 MB |
| klines (1m) | ~50 MB | ~18 GB（压缩后 ~2 GB） |
| decision_logs | ~500 KB | ~180 MB |

PoC 阶段无需关注以上指标。
