# FnAgent — 用户故事集

> 遵循 INVEST 原则：Independent（独立）、Negotiable（可协商）、Valuable（有价值）、Estimable（可估算）、Small（小粒度）、Testable（可测试）  
> 版本：v0.2 | 基于 2026-07-28 需求确认结果更新

---

## Epic 1：交易所对接与安全

### US-01：API Key 安全管理
> **作为** FnAgent 的使用者  
> **我想要** 在本地安全地配置我的币安 API Key  
> **以便** FnAgent 能够代表我在币安执行交易（现货+合约）

**验收标准：**
- [ ] 支持通过环境变量或本地配置文件注入 API Key + Secret
- [ ] API Key 在本地 AES-256 加密存储，不联网传输
- [ ] 显示 API Key 权限范围（只读/交易/提现），告警提现权限
- [ ] 支持一键验证 Key 是否有效（调用币安账户信息接口）
- [ ] 支持分别配置现货 API Key 和合约 API Key（可相同可不同）
- [ ] Key 信息日志脱敏显示（如 `AB12****xyz`）

**优先级：** P0 | **Story Point：** 5

> ⚠️ **v0.2 变更：** MVP 阶段仅个人使用，移除多用户注册/登录系统。API Key 本地配置，无需 Web 注册流程。

## Epic 2：策略管理

### US-03：选择并配置策略模板
> **作为** 一个投资者  
> **我想要** 从预设的策略模板中选择一个，填写参数就能运行  
> **以便** 不用写代码也能在现货或合约上做自动交易  

**验收标准：**
- [ ] 提供至少 3 种策略模板：网格交易、定投（DCA）、趋势跟踪
- [ ] 每个模板区分现货和合约版本（参数不同，如合约需配置杠杆倍数）
- [ ] 每个模板有清晰的参数说明和推荐默认值（保守型默认值，适合小资金）
- [ ] 支持选择交易品种（现货 / U 本位合约 / 币本位合约）
- [ ] 参数配置界面实时校验（如价格区间、杠杆上限等必须合法）
- [ ] **支持选择执行模式：全自动（规则引擎直接执行）或半自动（生成信号后需人工确认）**
- [ ] 配置完成后可在模拟环境试运行

**优先级：** P0 | **Story Point：** 13

---

### US-04：策略模拟验证
> **作为** 一个谨慎的投资者  
> **我想要** 在真实资金投入前，让策略在模拟环境中运行至少 24 小时  
> **以便** 确认策略逻辑无误再开启实盘  

**验收标准：**
- [ ] 一键切换到币安 Demo Mode / Testnet
- [ ] 模拟环境使用虚拟资金（默认 10,000 USDT）
- [ ] 模拟运行期间实时显示虚拟持仓和盈亏
- [ ] 模拟运行至少 24 小时且无异常后，才允许切换到实盘
- [ ] 模拟和实盘的数据严格隔离

**优先级：** P0 | **Story Point：** 8

---

### US-05：启动/停止/暂停策略
> **作为** 一个交易用户  
> **我想要** 随时启动、停止或暂停我的交易策略  
> **以便** 在市场剧烈波动时能及时干预  

**验收标准：**
- [ ] 一键启动策略（Agent 开始运行）
- [ ] 一键暂停策略（保留当前持仓，不再开新仓）
- [ ] 一键停止策略（平掉所有持仓后停止）
- [ ] 状态变更后 3 秒内生效
- [ ] 操作记录完整保留

**优先级：** P0 | **Story Point：** 5

## Epic 3：风控系统

### US-06：止损止盈设置
> **作为** 一个投资者  
> **我想要** 为每笔交易设置止损和止盈价位  
> **以便** 控制单笔亏损，锁定已有利润  

**验收标准：**
- [ ] 支持固定百分比止损（如 -5%）
- [ ] 支持固定金额止损（如 -100 USDT）
- [ ] 支持移动止损（Trailing Stop），随价格上涨自动上移止损位
- [ ] 止损触发后记录触发价格和原因
- [ ] 止盈支持分批止盈（如 50% 仓位在 +10% 止盈，剩余 50% 在 +20%）

**优先级：** P0 | **Story Point：** 8

---

### US-07：账户级风控
> **作为** 一个投资者  
> **我想要** 设置账户级别的风险参数  
> **以便** 即使策略逻辑出问题，也不会亏光所有资金  

**验收标准：**
- [ ] 设置日最大亏损限额（达到后当天停止交易）
- [ ] 设置最大回撤比例（如总资金回撤 30% 强制停止）
- [ ] 设置单币种最大仓位占比（如 BTC 不超过总资金的 50%）
- [ ] 设置最大同时持仓数量（如最多持有 5 个币种）
- [ ] 风控触发后推送通知并记录日志

**优先级：** P0 | **Story Point：** 8

## Epic 4：行情与交易执行

### US-08：实时行情监控
> **作为** 一个交易用户  
> **我想要** 在控制台看到实时 K 线、当前持仓和盈亏  
> **以便** 了解市场状况和我的资产变动  

**验收标准：**
- [ ] 实时推送选定交易对的最新价格（WebSocket）
- [ ] 显示当前持仓列表（币种、数量、成本价、现价、盈亏）
- [ ] 显示今日/本周/累计收益曲线
- [ ] 页面刷新延迟不超过 1 秒

**优先级：** P1 | **Story Point：** 13

---

### US-09：交易执行与订单管理
> **作为** Agent 引擎  
> **我想要** 通过币安 API 在现货和合约上准确执行买卖订单  
> **以便** 策略信号能转化为真实成交  

**验收标准：**
- [ ] **现货：** 支持市价单（Market）和限价单（Limit）
- [ ] **合约：** 支持市价单、限价单、止损市价单、止盈限价单
- [ ] 支持 OCO 订单（止损限价 + 止盈限价组合）
- [ ] 合约下单时校验杠杆倍数和保证金模式
- [ ] 订单状态实时跟踪（已提交 → 部分成交 → 完全成交 → 已取消）
- [ ] 限价单超时未成交自动取消并重试
- [ ] API 异常（限流、断连）自动重试，指数退避
- [ ] 区分现货和合约的 API 限流权重，统一管理

**优先级：** P0 | **Story Point：** 13

## Epic 5：AI 分析辅助（后期）

### US-10：LLM 市场分析报告
> **作为** 一个投资者  
> **我想要** Agent 每天生成一份市场分析报告（含技术面 + 情绪面）  
> **以便** 在做交易决策时有 AI 辅助参考  

**验收标准：**
- [ ] 每日定时生成分析报告（支持自定义时间）
- [ ] 报告包含：技术指标解读、市场情绪、风险评估、交易建议
- [ ] 支持本地 Ollama 模型（保护隐私）和云端 LLM 切换
- [ ] 分析报告的每条建议标注置信度
- [ ] 用户可选择"仅参考"或"自动执行"AI 建议

**优先级：** P1 | **Story Point：** 21

---

## Epic 6：信号跟单（后期）

### US-11：订阅交易信号
> **作为** 一个跟单用户  
> **我想要** 订阅一个信号源（如技术指标信号、KOL 信号）  
> **以便** 不需要自己分析也能跟着做交易  

**验收标准：**
- [ ] 支持接入外部信号源（Webhook URL / API）
- [ ] 信号格式标准化（币种、方向、仓位比例、止损、止盈）
- [ ] 信号到达后自动经过风控层审核
- [ ] 跟单执行结果可追溯（哪条信号→哪笔交易→盈亏多少）
- [ ] 支持设置跟单比例（如信号仓位的 50%）

**优先级：** P1 | **Story Point：** 13

---

## Epic 7：监控与报表

### US-12：交易日志与审计
> **作为** 一个投资者  
> **我想要** 查看所有交易的完整记录和决策理由  
> **以便** 复盘哪些策略有效，哪些需要调整  

**验收标准：**
- [ ] 每笔交易记录：时间、交易对、方向、数量、价格、策略来源、决策理由
- [ ] 支持按时间范围、策略、交易对筛选
- [ ] 支持导出 CSV
- [ ] 可视化：收益曲线、胜率、最大回撤、夏普比率

**优先级：** P0 | **Story Point：** 8

---

### US-13：告警通知
> **作为** 一个投资者  
> **我想要** 在关键事件发生时收到即时通知  
> **以便** 不用时刻盯着屏幕也能掌握情况  

**验收标准：**
- [ ] 支持以下通知渠道（至少 2 种）：Telegram Bot、邮件、Webhook
- [ ] 通知事件类型：止损触发、日亏损限额达到、API 连接异常、策略异常停止
- [ ] 用户可以自定义通知偏好（选择哪些事件、哪种渠道）
- [ ] 通知延迟不超过 30 秒

**优先级：** P1 | **Story Point：** 8
